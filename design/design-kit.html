06 — Handoff

Getting this into Figma

Two paths, depending on whether you want the visuals or the raw tokens.

A

Import this page as layers

In Figma, install the free html.to.design plugin → paste this page's URL. It rebuilds these swatches, components and screens as editable frames you can reframe for store shots.

B

Import the color tokens

Install Tokens Studio for Figma → Import → design/tokens.json from the repo. You get every light/dark color and radius as managed Figma variables.

C

Or just screenshot

Every screen here is a real HTML render. Screenshot a frame, drop it into a device mockup at the sizes in section 05, add a caption, and you have a listing image.
